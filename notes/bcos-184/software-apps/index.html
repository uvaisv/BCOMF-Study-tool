Operating Systems, SDLC & Apps

High Asked in 9 of 9 papers · avg 14 marks

Operating systems (Windows vs Linux), software platforms, SDLC for e-commerce, app development, app stores, mobile frameworks.

In your IGNOU bookBlock 3 · Unit 8 Electronic Commerce SoftwareBlock 5 · Unit 15 App Based CommerceBlock 1 · Unit 3 Technology used in E-Commerce (3.6 SDLC)Block 3 · Unit 9 Web Server Hardware and Software (9.5 Operating system)

Key points

  • Operating system: software that manages hardware and runs applications. Windows: proprietary, paid, user-friendly GUI. Linux: open source, free, secure, customisable, popular for servers.
  • Software platforms: desktop (Windows, macOS), mobile (Android, iOS), web, cloud (AWS), e-commerce platforms (Shopify, Magento, WooCommerce).
  • SDLC for e-commerce solutions: planning → requirement analysis → design → development → testing → deployment → maintenance.
  • App development process: idea and research → planning → UI/UX design → development (front end and back end) → testing → launch on app stores → updates.
  • App store: marketplace to distribute apps. Types: platform stores (Google Play, Apple App Store), third-party stores, enterprise stores.
  • Mobile development frameworks: native (Swift, Kotlin), cross-platform (Flutter, React Native), hybrid (Ionic).
  • E-commerce software for SMEs: ready-made storefronts, payment and inventory integration (Shopify, Dukaan).

Worked example

Example: SDLC for a grocery-delivery app

Planning: goals, budget and timeline. Requirement analysis: customers need search, cart, payment and tracking; the store needs stock and order screens. Design: screens (UI/UX), database and architecture. Development: front end in a cross-platform framework (Flutter), back end on a cloud server. Testing: bugs, payments, load. Deployment: publish on Google Play and the App Store. Maintenance: fixes and new features from user feedback.
