Websites, Hosting & Web Servers

Critical Asked in 8 of 9 papers · avg 23 marks

Website types and development, web hosting and its types, web server vs application server, HTTP vs HTTPS, Internet vs WWW.

In your IGNOU bookBlock 3 · Unit 7 Website DevelopmentBlock 3 · Unit 9 Web Server Hardware and Software

Key points

  • Website: collection of related web pages under one domain. Types: static vs dynamic; personal, business/corporate, e-commerce, blog, portfolio, informational, social media, educational.
  • Web development process: information gathering → planning (sitemap) → design → content writing → coding → testing → launch → maintenance.
  • Web hosting: storing a website on a server connected to the internet. Types: shared, VPS, dedicated, cloud, managed WordPress, reseller, colocation.
  • Web server: serves static content over HTTP (Apache, Nginx). Application server: runs business logic and dynamic content (Tomcat, JBoss).
  • HTTP: unencrypted, port 80. HTTPS: encrypted with SSL/TLS, port 443, needed for payments.
  • Internet: the global network of networks. WWW: a service on the internet — linked web pages accessed by browsers. Evolution: Web 1.0 (read-only), Web 2.0 (interactive, social), Web 3.0 (semantic, decentralised).
  • A mail server stores and delivers e-mail; web server hardware ranges from a single machine to server farms and cloud instances, chosen by traffic, storage and uptime needs.

Worked example

Example: from a small site to an online store

A dental clinic starts with a static site — timings, services, map — on cheap shared hosting.

A furniture shop wants online orders: it needs a dynamic site with a product database and cart, on cloud hosting that can handle festival traffic. Its application server runs the order logic, the web server sends pages to browsers, and HTTPS (padlock, port 443) protects customers' payment details.
