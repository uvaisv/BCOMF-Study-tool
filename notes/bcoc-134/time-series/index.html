Time Series

Critical Asked in 11 of 11 papers · avg 17 marks

Every session: components/utility theory, or fitting a straight-line trend by least squares.

In your IGNOU bookBlock 6 · Unit 18 Time Series Analysis

Key points

  • Time series: data arranged in order of time.
  • Components: secular trend, seasonal variation, cyclical variation, irregular variation.
  • Models: additive Y = T + S + C + I; multiplicative Y = T × S × C × I.
  • Trend methods: freehand, semi-averages, moving averages, least squares.
  • Utility: understand past behaviour, forecast, compare, plan business activity.
  • Preliminary adjustments: calendar days, population, price changes, comparability of data.

Worked example

Example: trend by least squares

Sales (₹ lakh), 2020–2024: 40, 44, 50, 52, 59. Take X = year − 2022, so X = −2, −1, 0, 1, 2 and ΣX = 0.

ΣY = 245, ΣXY = −80 − 44 + 0 + 52 + 118 = 46, ΣX² = 10.

a = 245/5 = 49; b = 46/10 = 4.6 → Yc = 49 + 4.6X.

Trend values: 39.8, 44.4, 49.0, 53.6, 58.2.

Forecast for 2026 (X = 4): 49 + 18.4 = ₹67.4 lakh.

Diagrams

How to solve

  1. Take X = year − middle year (odd number of years) so ΣX = 0.
  2. a = ΣY / n, b = ΣXY / ΣX².
  3. Trend Yc = a + bX for each year.
  4. Forecast: put the X of the required year into Yc = a + bX.

Formulas

Yc = a + bX
a = ΣY/n, b = ΣXY/ΣX² (when ΣX = 0)

Common mistakes

  • Using the actual year instead of the deviation X.
  • Wrong X for the forecast year.
