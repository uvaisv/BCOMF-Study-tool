Differentiation (dy/dx)

Critical Asked in 9 of 11 papers · avg 16 marks

Usually 'find dy/dx, any four' for 20 marks — pure practice, very predictable.

In your IGNOU bookBlock 2 · Unit 7 Concept of Differentiation

Key points

  • Derivative dy/dx = rate of change of y with respect to x.
  • Standard results: d/dx(xⁿ) = n·xⁿ⁻¹; d/dx(constant) = 0; d/dx(eˣ) = eˣ; d/dx(log x) = 1/x; d/dx(aˣ) = aˣ·log a.
  • Implicit functions (e.g. x² + y² = 25): differentiate both sides, collect dy/dx terms.
  • Parametric (x = at², y = 2at): dy/dx = (dy/dt) ÷ (dx/dt).
  • Function of a function (y = u³, u = 3x + 9): chain rule dy/dx = dy/du × du/dx.
  • Differentiation by first principle: dy/dx = lim h→0 [f(x + h) − f(x)] / h.

Worked examples

Example: product, quotient and chain rules

Product: y = (x² + 1)(3x − 2) → dy/dx = (x² + 1)·3 + (3x − 2)·2x = 9x² − 4x + 3.

Quotient: y = (2x + 1)/(x − 3) → dy/dx = [(x − 3)·2 − (2x + 1)·1]/(x − 3)² = −7/(x − 3)².

Chain: y = (3x + 9)³ → put u = 3x + 9: dy/dx = 3u² × 3 = 9(3x + 9)².

Example: implicit, parametric and logarithmic

Implicit: x² + y² = 25 → 2x + 2y·dy/dx = 0 → dy/dx = −x/y; at (3, 4) the slope is −3/4.

Parametric: x = at², y = 2at → dx/dt = 2at, dy/dt = 2a → dy/dx = 2a/2at = 1/t.

Logarithmic: y = xˣ → log y = x·log x → (1/y)·dy/dx = log x + 1 → dy/dx = xˣ(1 + log x).

How to solve

  1. Identify the form: sum, product, quotient, chain, implicit or parametric.
  2. Write the rule you are using as the first line.
  3. Differentiate each part, then simplify.
  4. For xˣ type: take log on both sides, then differentiate (logarithmic differentiation).

Formulas

Product: d(uv)/dx = u·dv/dx + v·du/dx
Quotient: d(u/v)/dx = (v·du/dx − u·dv/dx) / v²
Chain: dy/dx = dy/du × du/dx

Common mistakes

  • Wrong sign order in the quotient rule (it is v·u′ − u·v′).
  • Forgetting to multiply by du/dx in the chain rule.
