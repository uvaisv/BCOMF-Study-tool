Functions in Business (Cost, Revenue, Profit)

High Asked in 8 of 11 papers · avg 14 marks

Cost, revenue, profit and demand functions, break-even, and composite/inverse functions (f∘g, g∘f).

In your IGNOU bookBlock 2 · Unit 5 Mathematical FunctionsBlock 2 · Unit 9 Application of Derivatives (9.2–9.6)

Key points

  • Function: a rule giving exactly one output for each input.
  • Types: linear (y = a + bx), quadratic, absolute value |x|, step function, exponential.
  • Cost function C(x) = fixed cost + variable cost × x. Average cost = C(x)/x.
  • Revenue function R(x) = price × x. Profit P(x) = R(x) − C(x).
  • Demand function: quantity demanded as a function of price.
  • Composite function: (f∘g)(x) = f(g(x)). Inverse function: reverses f, exists when f is one-to-one.
  • Types in the book: algebraic, transcendental (exponential, logarithmic), inverse and composite functions; business functions include demand, supply, cost, revenue and profit.

Worked examples

Example: cost, revenue, profit and break-even

Fixed cost ₹60,000; variable cost ₹30 per unit; selling price ₹50.

C(x) = 60,000 + 30x; R(x) = 50x; P(x) = R − C = 20x − 60,000.

Break-even: 50x = 60,000 + 30x → x = 3,000 units (= 60,000 ÷ (50 − 30)).

At 5,000 units: profit = ₹40,000; average cost = (60,000 + 1,50,000) ÷ 5,000 = ₹42 per unit.

Example: composite functions

f(x) = 2x + 1, g(x) = x².

f∘g(x) = f(x²) = 2x² + 1; g∘f(x) = (2x + 1)² = 4x² + 4x + 1.

At x = 2: f∘g = 9 but g∘f = 25 — the order matters.

How to solve

  1. Break-even: set R(x) = C(x) and solve for x.
  2. f∘g: substitute g(x) wherever x appears in f.
  3. g∘f: substitute f(x) into g — usually a different answer.

Formulas

BEP (units) = Fixed cost ÷ (Selling price − Variable cost per unit)

Common mistakes

  • Mixing up the order in f∘g and g∘f.
