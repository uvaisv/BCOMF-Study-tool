Regression

High Asked in 6 of 11 papers · avg 12 marks

Regression equations/coefficients by least squares, and theory on properties of regression coefficients.

In your IGNOU bookBlock 5 · Unit 16 Simple Linear Regression

Key points

  • Regression estimates the value of one variable from another.
  • Two lines: Y on X (estimate Y) and X on Y (estimate X); both pass through (x̄, ȳ).
  • Properties: r = ±√(bᵧₓ × bₓᵧ); both coefficients have the same sign; if one is > 1 the other is < 1; independent of change of origin but not of scale.

Worked example

Example: both regression lines

x: 1, 2, 3, 4, 5; y: 2, 4, 5, 4, 5. Means x̄ = 3, ȳ = 4.

Deviations dx: −2, −1, 0, 1, 2; dy: −2, 0, 1, 0, 1. Σdxdy = 6, Σdx² = 10, Σdy² = 6.

bᵧₓ = 6/10 = 0.6 → Y on X: y − 4 = 0.6(x − 3), i.e. y = 0.6x + 2.2.

bₓᵧ = 6/6 = 1 → X on Y: x − 3 = 1(y − 4), i.e. x = y − 1.

r = √(0.6 × 1) = 0.77. Estimate y when x = 6: 0.6 × 6 + 2.2 = 5.8.

Diagram

How to solve

  1. Table: x, y, x², y², xy (or deviations from the means).
  2. bᵧₓ = [nΣxy − ΣxΣy]/[nΣx² − (Σx)²]; bₓᵧ = [nΣxy − ΣxΣy]/[nΣy² − (Σy)²].
  3. Y on X: y − ȳ = bᵧₓ(x − x̄). X on Y: x − x̄ = bₓᵧ(y − ȳ).

Formulas

y − ȳ = bᵧₓ(x − x̄)
r = ±√(bᵧₓ · bₓᵧ)

Common mistakes

  • Swapping bᵧₓ and bₓᵧ.
  • Giving r a sign different from the coefficients.
