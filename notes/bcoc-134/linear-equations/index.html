Inverse Matrix, Cramer's Rule & Equations

Moderate Asked in 6 of 11 papers · avg 10 marks

Solve 2 or 3 equations by Cramer's rule or the matrix (inverse) method, or find an inverse.

In your IGNOU bookBlock 1 · Unit 3 Inverse of MatricesBlock 1 · Unit 2 Determinants (2.5 Cramer's rule)

Key points

  • A system AX = B has solution X = A⁻¹B when |A| ≠ 0.
  • Inverse exists only for a square matrix with non-zero determinant.
  • Properties: (A⁻¹)⁻¹ = A; (AB)⁻¹ = B⁻¹A⁻¹; (Aᵀ)⁻¹ = (A⁻¹)ᵀ; AA⁻¹ = A⁻¹A = I.
  • The book gives two routes to the inverse: determinant and adjoint, and elementary row operations ([A | I] → [I | A⁻¹]).
  • Rank: the maximum number of linearly independent rows (= columns); rank ≤ smaller of m and n. An n × n matrix has an inverse only if its rank is n.

Worked example

Example: Cramer's rule

Solve x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2.

D = |1 1 1; 2 −1 1; 1 2 −1| = 1(1 − 2) − 1(−2 − 1) + 1(4 + 1) = 7.

Replace column 1 with (6, 3, 2): D₁ = 7; column 2: D₂ = 14; column 3: D₃ = 21.

x = 7/7 = 1, y = 14/7 = 2, z = 21/7 = 3.

Check in equation 3: 1 + 4 − 3 = 2 ✓.

How to solve

  1. Cramer's rule: find D = |A|. Replace column 1 by constants → D₁; column 2 → D₂; column 3 → D₃.
  2. x = D₁/D, y = D₂/D, z = D₃/D.
  3. Inverse method: find |A|, the cofactor matrix, adjoint (transpose of cofactors), then A⁻¹ = adj A ÷ |A|.
  4. Check: substitute the answers back into one equation.

Formulas

A⁻¹ = adj(A) / |A|
Cofactor Cᵢⱼ = (−1)ⁱ⁺ʲ × Minorᵢⱼ

Common mistakes

  • Forgetting the sign pattern (+ − +) for cofactors.
  • Not transposing the cofactor matrix to get the adjoint.
