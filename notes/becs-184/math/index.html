Sets, Relations, Logic & Mathematical Modelling

High Asked in 5 of 8 papers · avg 10 marks

Sets and their representation, types of sets, set relations and operations with their laws, relations and functions, logic (statements, connectives, arguments, symbolic language), proof techniques and the use of mathematical modelling in economics.

In your IGNOU bookBlock 1 · Unit 1 Mathematical Concepts

Key points

  • A set is a well-defined collection of distinct objects. Representation: roster or tabular form, V = {a, e, i, o, u}; set-builder form, {x : x ∈ N, x < 10}.
  • Special sets: empty (null) set ∅, universal set U, finite and infinite sets, singleton, subsets and proper subsets, equal sets, intervals as sets, number sets (N, Z, Q, R).
  • Operations: union (X ∪ Y), intersection (X ∩ Y), difference (X − Y), symmetric difference (X Δ Y = (X ∪ Y) − (X ∩ Y)) and complement (X′ = U − X). Laws: commutative, associative, distributive, identity, idempotent, and De Morgan's laws (X ∪ Y)′ = X′ ∩ Y′ and (X ∩ Y)′ = X′ ∪ Y′.
  • Cartesian product X × Y = all ordered pairs (x, y). A relation from X to Y is a subset of X × Y, with a domain, range and co-domain. A function relates each element of the domain to exactly one element of the co-domain.
  • Logic is about reasoning correctly — deriving conclusions from given facts so that every careful person reaches the same answer. Kinds of reasoning: deduction, induction and abduction.
  • Symbolic language: statements are named P, Q, …; truth values True and False; connectives — negation (~), conjunction (∧), disjunction (∨), conditional (→) and biconditional (↔), defined by truth tables. An argument is a set of premises and a conclusion.
  • Logic matters in data analysis because analysts must state assumptions clearly, draw valid conclusions from data, avoid fallacies (e.g. treating correlation as causation) and build and check models.
  • Proof techniques: direct proof and counter-example, contradiction and contrapositive, proof by cases, existence proof, mathematical induction, proof of equivalences.
  • Mathematical modelling (five-step process): define the economic problem → translate it into mathematical form (the model) → solve with mathematical tools → translate the result back into economics → check that it makes sense. Example: demand Q = 100 − 2P and supply Q = 20 + 2P give equilibrium P = 20, Q = 60.

Worked examples

Example: set operations

U = {1, 2, …, 8}, X = {1, 2, 3, 4}, Y = {2, 4, 5, 7}.

X ∪ Y = {1, 2, 3, 4, 5, 7}; X ∩ Y = {2, 4}; X − Y = {1, 3}; X Δ Y = {1, 3, 5, 7}.

X′ = {5, 6, 7, 8}, Y′ = {1, 3, 6, 8} → X′ ∩ Y′ = {6, 8} = (X ∪ Y)′ — De Morgan's law checks out.

Example: modelling and logic

Modelling: 'At what price does the market clear?' → model: demand Q = 100 − 2P, supply Q = 20 + 2P → solve 100 − 2P = 20 + 2P → P = 20, Q = 60 → interpret: price ₹20, 60 units → check: both equations give 60 ✓.

Logic: P = 'it rains', Q = 'sales of umbrellas rise'. P → Q is false only when it rains and sales do not rise. From 'P → Q' and 'P', we may conclude Q (valid); from 'P → Q' and 'Q' we may not conclude P (a common fallacy).

How to write the answer

Definition → representation or operations with small examples (Venn-type) → laws or uses → conclusion.

Common mistakes

  • Repeating elements inside a set, e.g. {1, 2, 2, 3}.
  • Confusing subset (⊆) with element (∈).
