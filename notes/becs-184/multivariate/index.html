Multivariate Data Analysis

High Asked in 6 of 8 papers · avg 10 marks

Meaning of multivariate analysis, dependence and interdependence techniques, the main techniques (factor, multiple regression, discriminant and logistic, canonical correlation, MANOVA, conjoint, cluster, perceptual mapping, correspondence) and guidelines for interpreting results.

In your IGNOU bookBlock 3 · Unit 9 Multivariate Data Analysis

Key points

  • Univariate analysis studies one variable, bivariate two, multivariate three or more variables together — needed because economic and social outcomes depend on many interacting factors.
  • Classification: dependence methods (some variables explain others) — multiple regression, multiple discriminant analysis, MANOVA, canonical correlation; interdependence methods (no dependent variable) — factor analysis, cluster analysis, multidimensional scaling, latent structure analysis. The choice also depends on whether data are metric (interval, ratio) or non-metric (nominal, ordinal).
  • Factor / principal component analysis: condenses many correlated variables into a few underlying factors (e.g. 20 survey items → 3 factors of satisfaction).
  • Multiple regression: one metric dependent variable explained by several independent variables (Y = a + b₁X₁ + b₂X₂ + …), e.g. sales on price, advertising and income.
  • Discriminant analysis and logistic regression: predict a categorical outcome (default / no default; buyer / non-buyer).
  • Canonical correlation: relationship between two sets of variables. MANOVA: compares group means on several dependent variables at once.
  • Conjoint analysis: how customers trade off product features. Cluster analysis: groups similar cases (market segments). Perceptual mapping: a visual map of how consumers see competing brands. Correspondence analysis: a picture of cross-tabulated categories.
  • Guidelines for interpreting results: establish practical as well as statistical significance; remember that sample size affects all results; know your data (outliers, missing values, assumptions); strive for model parsimony; look at your errors; validate the results; use software carefully.
  • Structured approach (six steps): define the problem, objectives and technique → develop the analysis plan → evaluate the assumptions → estimate the model and assess fit → interpret the variate → validate the model.

Worked example

Example: choosing a multivariate technique

Predict a household's monthly spending from income, family size and education → multiple regression (dependence, metric outcome).

Predict whether a borrower will default (yes/no) → discriminant analysis or logistic regression.

Group 1,000 customers into segments by buying habits → cluster analysis (interdependence).

Reduce 20 satisfaction questions to a few underlying factors → factor analysis.

Compare three teaching methods on both marks and attendance together → MANOVA.

How to write the answer

Meaning → classification → 4–6 techniques with one-line use and an example each (or the guidelines, if asked) → conclusion.

Common mistakes

  • Listing techniques without saying which are dependence and which interdependence methods.
  • Treating statistical significance alone as proof that a result matters.
