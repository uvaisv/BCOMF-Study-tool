Computer Fundamentals & Generations

High Asked in 7 of 9 papers · avg 12 marks

What a computer is, generations, types (analog/digital/hybrid, micro to super), hardware components, applications.

In your IGNOU bookBlock 1 · Unit 1 Introduction to ComputerBlock 1 · Unit 2 Application of Computers

Key points

  • A computer is a programmable electronic device that does four things: accepts data (input), processes it, gives results (output) and stores them.
  • Hardware: input devices, CPU (ALU, control unit, registers), memory (RAM, ROM), storage and output devices. Software makes the hardware useful.
  • The book's six generations: 1st (1940–56) vacuum tubes and machine language; 2nd (1956–63) transistors; 3rd (1964–71) integrated circuits; 4th (1972–2010) microprocessors, networks and the internet; 5th (2010–20) parallel processing and AI; 6th (2020 on) nanotechnology.
  • Classification — by purpose: general or special purpose; by size and capacity: micro, mini, mainframe, super; by technology: analog (continuous data), digital (discrete) and hybrid (both).
  • Mainframes serve many users and huge transaction loads (banks); supercomputers are the fastest, used for scientific work such as weather forecasting.
  • Applications: business, education, banking, insurance, healthcare, defence, communication and personal use.
  • Advantages: speed, accuracy, multitasking, storage, data security. Disadvantages: fewer jobs, loss of privacy, viruses and cybercrime.

Worked examples

Examples: classify the computer

A desktop in an office → general-purpose microcomputer. An ATM or a washing-machine controller → special-purpose. A bank's central system handling lakhs of transactions → mainframe. Weather forecasting → supercomputer. A hospital ICU machine that measures a patient's temperature and pulse (continuous) and shows them as numbers (digital) → hybrid.

Example: input, process, output, storage

In a billing counter: barcodes scanned (input) → prices looked up and totalled by the CPU (processing) → bill printed (output) → sale saved in the database (storage).

How to write the answer

Definition with a block diagram (Input → CPU → Output, with memory) → classification table → applications.
