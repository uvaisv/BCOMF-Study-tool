MS Excel Features & Functions

Moderate Asked in 7 of 9 papers · avg 10 marks

Charts, worksheets, relative vs absolute addressing, logical and financial functions, formulas vs functions.

In your IGNOU bookBlock 5 · Unit 16 Spreadsheets ConceptBlock 5 · Unit 17 Formulas and FunctionsBlock 5 · Unit 18 Graphical Presentations of DataBlock 5 · Unit 19 Advanced Options in Spreadsheets (19.2–19.4)

Key points

  • A spreadsheet arranges data in rows and columns for organising and analysing, especially numbers. Excel screen: ribbon, quick access toolbar, title bar, formula bar, worksheet tabs.
  • Worksheets can be named, inserted, deleted, grouped, ungrouped, moved, hidden, linked and protected.
  • Addressing: relative (A1) changes when copied; absolute ($A$1) stays fixed; mixed ($A1 or A$1).
  • A formula is an expression of values, operators and cell references (=A1+B1). A function is a pre-defined formula: '=' + name + arguments (=SUM(A1:A10)).
  • Array formula (CSE — Ctrl+Shift+Enter) does many calculations on a range at once.
  • Function groups: statistical, financial, logical (IF, AND, OR), date and time, text (CONCATENATE), lookup (VLOOKUP, HLOOKUP) and math.
  • Charts make data readable; pivot tables and pivot charts summarise and cross-tabulate large data sets.
  • Sort and filter go together to prepare data; cell comments explain entries.

Worked examples

Example: relative and absolute references

Sales are in A3:A10 and the commission rate is in B1. In B3 type =A3*$B$1 and copy it down: A3 changes to A4, A5… (relative), but $B$1 stays fixed (absolute).

Example: useful functions

=SUM(C2:C31) totals a column. =IF(C2>=40,"Pass","Fail") marks each student. =VLOOKUP(102, A2:C50, 3, FALSE) finds item code 102 in the first column and returns its price from the third column. A pivot table then summarises sales by region and month in a few clicks.
