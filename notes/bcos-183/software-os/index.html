Software & Operating Systems

Critical Asked in 8 of 9 papers · avg 17 marks

System vs application software, OS functions and types, language processors, utility programs, open source.

In your IGNOU bookBlock 1 · Unit 4 Basics of Computer Software

Key points

  • Software is of two types: system software runs the hardware (operating system, drivers, utilities); application software does user tasks (Word, Excel, Tally, SPSS, Photoshop).
  • Operating system: manages hardware and gives services to programs. Functions: process, memory, file, device and security management, and the user interface.
  • Types of OS: batch, time-sharing, real-time, distributed, network, desktop (Windows, Linux) and mobile (Android, iOS).
  • Windows is a proprietary graphical OS used on desktops and laptops; Android is an open-source, Linux-based mobile OS now also used on wearables, TVs and consoles.
  • Google Play Store is Android's digital store for downloading apps.
  • Language processors: compiler (translates the whole program at once), interpreter (line by line, easier to debug), assembler (assembly language to machine code).
  • Utility programs maintain the system: antivirus, disk clean-up, backup, compression, defragmenter.
  • Free and open-source software: the source code can be used, changed and shared (Linux, LibreOffice).

Worked examples

Examples: which kind of software?

Windows 11 and Android → system software (operating systems). A printer driver and an antivirus → system software (driver and utility). Tally, MS Excel and Photoshop → application software. LibreOffice and Linux → free and open-source software.

Example: compiler vs interpreter

A C program is compiled — the whole program is translated into machine code first, and errors are reported together. A Python program is interpreted — run line by line, stopping at the first error, which makes debugging easier.

How to write the answer

Definition → functions or types as headed points → comparison table → examples.
