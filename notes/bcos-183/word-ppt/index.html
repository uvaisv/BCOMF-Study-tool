MS Word, PowerPoint & Google Docs

Critical Asked in 9 of 9 papers · avg 20 marks

Mail merge, word processing features, equation editor, presentations and animation, Google Docs vs Word.

In your IGNOU bookBlock 3 · Unit 11 Advanced Tools Using Word ProcessingBlock 3 · Unit 9 Basics of Word ProcessingBlock 3 · Unit 10 Working with Word ProcessingBlock 4 · Unit 13 Working with PowerPoint

Key points

  • Word processing: creating, editing, formatting, storing and printing documents; packages include MS Word, WordStar, WordPerfect and Google Docs.
  • MS Word 2010 tabs: File, Insert, Page Layout, References, Mailings, Review and View. Views: Print Layout, Full Screen Reading, Web Layout, Outline and Draft.
  • Editing and formatting: copy, undo/redo, find and replace, fonts, line spacing, borders and shading, bullets, indenting, margins, header and footer, tables, spell check, WordArt and SmartArt.
  • Mail merge (Mailings tab) makes many personalised copies: create the main document → create the data source → insert merge fields → merge.
  • Equation editor (Insert tab) inserts ready or custom equations; Track Changes (Review tab) records edits for review.
  • Referencing tools: footnote/endnote, index, table of contents, bookmark (named place to jump to), cross-reference, citation, placeholder and bibliography.
  • Google Docs is free, web-based and saves to the cloud so others can edit at once; Word files live on your computer unless shared.
  • PowerPoint: insert a slide from Home → New Slide, Ctrl+M, or right-click → New Slide; add graphs, diagrams, pictures, sound and video; save to external memory or the cloud.

Worked examples

Example: mail merge for 200 invitation letters

Write the main letter once in Word. Create the data source — an Excel sheet with Name, Address and City for 200 guests. Insert merge fields («Name», «Address») in the letter from the Mailings tab. Finish and merge to get 200 personalised letters, printed or e-mailed.

Example: a project report in Word

Use Heading styles for chapters and insert an automatic table of contents (References tab). Add footnotes for sources and a bibliography from the citations. Turn on Track Changes so the guide's corrections show up for you to accept or reject.
