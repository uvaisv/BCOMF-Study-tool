Networks, Internet & E-mail

Critical Asked in 7 of 9 papers · avg 12 marks

Network types, internet vs intranet vs extranet, WWW, URLs and domains, browsers, e-mail protocols, cloud computing.

In your IGNOU bookBlock 2 · Unit 7 Internet Services and E-mail ConfigurationBlock 1 · Unit 2 Application of Computers (2.7 Computer networks)Block 1 · Unit 3 Web Applications (3.4 Cloud)

Key points

  • A computer network is a chain of nodes linked by communication channels that share data, programs and databases.
  • Types by area: PAN (one person, about 10 m), LAN (one building), MAN (a town, city or campus — several LANs), WAN (a country or continents; the internet is a public WAN) and HAN (a home).
  • Internet: a global network of networks working on common protocols. Intranet: a private network inside one organisation. Extranet: part of an intranet opened to partners.
  • Internet services: e-mail, World Wide Web, web services, FTP (file transfer), chat rooms, mailing lists and newsgroups.
  • The WWW is a service on the internet (linked web pages); the internet is the network itself. A web browser lets you view hypertext pages — graphical (Chrome) or non-graphical (text only).
  • E-mail protocols: SMTP sends mail; POP3 downloads mail to one device (usually removing it from the server); IMAP keeps mail on the server and syncs across devices.
  • URL: the address of a web page. A domain name (e.g. ignou.ac.in) is a memorable shortcut for an IP address; DNS translates names into IP addresses.
  • Top-level domains: gTLD (generic — .com, .org) and ccTLD (country code — .in, .uk).
  • Cloud computing: using remote internet servers to store, manage and process data instead of a local computer; providers charge by use (Google Drive).

Worked examples

Examples: which network?

Phone connected to a smartwatch by Bluetooth → PAN. Computers in one office connected to a shared printer → LAN. A college's buildings across a city connected together → MAN. A bank linking its branches across India → WAN. The staff-only portal of a company → intranet; opening part of it to suppliers → extranet.

Example: reading a URL and choosing an e-mail protocol

In https://www.example.com/courses/index.html — 'https' is the protocol, 'www.example.com' the domain name (.com is a generic top-level domain), and '/courses/index.html' the path to the page. DNS turns the domain name into the server's IP address.

Someone who reads mail on a phone and a laptop should use IMAP, so both show the same mailbox. With POP3, mail downloaded to one device may disappear from the other.

How to write the answer

Definition → types in a table (range, example) → comparisons → conclusion.
